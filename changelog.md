# Changelog

## v0.1.0 — 2026-11-24

This release updates the Sherlock example using the companion source from *Programming Erlang, Second Edition*.

### Changes

- Started from [Joe Armstrong's `sherlock` repository](https://github.com/joearms/sherlock), “Sherlock's last case.”
- Updated 11 Erlang source files in `src/` from `jaerlang2-code/code/sherlock/src/` in the book's code archive.
- Added `.tool-versions` with the local development tool versions:
  - Erlang/OTP 25.2
  - Rebar3 3.20.0-v25.2
  - LFE 2.2.0-v25.2
  - Elixir 1.14.3-otp-25
  - Gleam 0.26.1-v25

This release is an Erlang source update; it does not yet include an LFE port.
